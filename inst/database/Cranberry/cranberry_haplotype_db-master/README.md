# cranberry_haplotype_db

## This is v1 cranberry DArTag panel containing 3,059 markers (including 126 MAS and 55 markers from the 3K blueberry DArTag panel)
### There are markers located within 81 bp distance, which produce redundant information. For any genotyping project, need to remove duplicated/closeby markers (15 bp distance) prior to analysis. The final set contains 2,706 markers for downstream analysis
