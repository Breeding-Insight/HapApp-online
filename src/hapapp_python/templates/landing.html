Process your DArTag reports against the public Breeding Insight microhaplotype database reference

HapApp performs QC and filters raw DArTag Missing Allele Discovery Count (MADC) reports, assigns every allele a fixed microhaplotype ID from the public Breeding Insight microhaplotype database for your species, and adds any newly discovered microhaplotypes to it.

How HapApp works

HapApp runs the same Breeding Insight pipeline that built the published databases, so your report is processed the same way the reference was. There's no software to install and no command line.

  1. File checks. HapApp confirms that your upload is a raw, unprocessed DArTag MADC report and that its markers match a supported species panel.
  2. Quality control. Marker IDs are converted to a standard chromosome-and-position format. Microhaplotypes are kept only if they appear in at least 10 samples or 5% of samples (whichever is smaller) with at least 2 reads each, which removes rare sequencing artifacts.
  3. Fixed IDs. Each microhaplotype is compared with the species database using BLAST. Known microhaplotypes keep their established IDs, new ones get new unique IDs, and duplicate sequences are merged so each has exactly one ID.
  4. Download your results. You receive a processed MADC with fixed allele IDs, ready for downstream analysis. New microhaplotypes are added to the database, and your processed report, metadata and workflow log are shared with Breeding Insight for review.

Why process against a public reference?

DArTag reports name alleles project by project, so the same microhaplotype can carry different labels in different orders, even within your own program. Processing against the public database gives each microhaplotype one permanent ID. You can combine data across years and projects, compare your germplasm with other programs, and move straight into downstream analysis.

Breeding Insight's Microhaplotype Database

Breeding Insight maintains standardized, species-specific microhaplotype databases built from DArTag data from USDA-ARS and university breeding programs. Each processed report makes the reference more complete for everyone who uses it. The framework and the initial databases are described in a peer-reviewed publication.
